# Say It! Speech Games

Browser-based speech games: see a picture, say the answer into the microphone, get a fanfare.

| App | Folder |
|-----|--------|
| Dog Breeds | `dog-breeds/` |
| Dinosaurs | `dinosaurs/` |
| Kitchen Appliances | `kitchen-appliances/` |
| Vehicles | `vehicles/` |

## Adding a new app
1. Create a new folder with an `index.html`.
2. Add a link to it in the root `index.html`.

## Hosting
Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
Pages is served over HTTPS, so the browser remembers microphone permission.
