# Where Is? 🔍

A fun, voice-controlled guessing game for young children – **now with all 56 pictures!**

The child looks at a colourful picture, hears a friendly **British female narrator** ask “Where is the tiger?”, and answers out loud (or by typing). The game checks the answer and gives cheerful feedback.

## Features

- **All 56 pictures** from the original set
- British English narrator (uses the device’s speech synthesis)
- Microphone support (Web Speech API) – works best in Chrome / Edge
- Type-your-answer fallback for any device
- Score tracking and encouraging end screen
- Fully responsive – great on phones, tablets and desktops
- No accounts, no ads, no tracking
- Works offline after the first load

## How to play

1. Open `index.html` in a modern browser (or host the folder on GitHub Pages).
2. Tap **Start Game!**
3. Look at the picture.
4. Listen to the question (or read it).
5. Tap the microphone and say your answer, **or** tap “Type Answer”.
6. Get feedback and move to the next picture.

## Deploying to GitHub Pages

1. Create a new repository on GitHub.
2. Upload the entire contents of this folder (`index.html`, `images/`, `README.md`).
3. Go to **Settings → Pages**.
4. Set Source to “Deploy from a branch” and choose the `main` branch / root.
5. Your game will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
